# WeatherApp

Hello! This is my first 'project' using python.
When this app is ran it gives a popup notification telling the user the desired citys tempature and windspeed.

## Features
- Asks the city
- Asks what information you want to know
- Prints them out via popup -notification that lasts for 5 seconds.
- Keeps running until user types 'exit'
- '-help' shows inputs.

## Usage
1. Make sure you have [uv](https://github.com/astral-sh/uv) installed.
2. Run the script:
    ```bash
    uv run weatherapp.py
    ```
3. Type in the city of which you want the status of.
4. Type in the information you want to know.
